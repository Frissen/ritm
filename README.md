# Ритм — трекер привычек

**Ритм** — кроссплатформенный трекер привычек, который работает прямо в браузере. Без серверов, без регистрации в интернете: все данные хранятся локально на устройстве, а для переноса предусмотрены файл резервной копии, код синхронизации и необязательная облачная синхронизация.

Версия: **1.4**

---

## 1. Как запустить

### Быстрый способ
Откройте файл `index.html` двойным щелчком — приложение запустится в браузере.

### Полноценный способ (рекомендуется)
Возможности **офлайн-режима (PWA)**, **системных уведомлений** и установки на телефон/рабочий стол требуют, чтобы страница открывалась по протоколу `http://` или `https://` (ограничение браузеров для `file://`).

Запустите любой локальный веб-сервер в папке проекта, например:

```powershell
# если установлен Python
python -m http.server 8080
```

Затем откройте `http://localhost:8080/`.

### Установка как приложение
- **Десктоп (Chrome / Edge):** значок «Установить» в адресной строке.
- **Android:** «Добавить на главный экран».
- **iOS Safari:** «Поделиться» → «На экран «Домой»».

После установки приложение работает как отдельное окно и доступно офлайн.

### Приложение для Windows (.exe)
Готовая сборка — `dist\Ritm.exe`. Двойной щелчок открывает приложение в отдельном окне (хост WebView2). При первом запуске на рабочем столе и в меню «Пуск» создаются ярлыки **«Ритм»** и **«Ритм — виджет»**.

- **Главное окно** — полная версия приложения.
- **Виджет** (`Ritm.exe --widget` или ярлык «Ритм — виджет») — компактное окно поверх других окон: привычки на сегодня, быстрая отметка и кнопка перехода в главное окно. Главное окно и виджет синхронизируются автоматически.

Данные десктопной версии хранятся в `%LOCALAPPDATA%\Ritm` (отдельный профиль WebView2, не совпадает с браузерным). Для переноса используйте экспорт/импорт файла или код синхронизации.

Требуется **Microsoft Edge WebView2 Runtime** — на Windows 10/11 обычно уже установлен.

**Пересборка:** `powershell -ExecutionPolicy Bypass -File desktop\build.ps1` (нужны .NET Framework 4.x и WebView2 SDK; подробности в `desktop\build.ps1`).

### Приложение для iPhone (iOS)

Приложение доступно как **PWA**: откройте сайт в Safari → «Поделиться» → «На экран «Домой»». Появится иконка, приложение работает в полноэкранном режиме и офлайн.

Для установки **файлом `.ipa`** в проекте настроена сборка на macOS-раннере GitHub Actions (собрать IPA на Windows нельзя — нужен Xcode). Обёртка сделана через Capacitor (`capacitor-ios/`), сборка выполняется автоматически при изменениях в `capacitor-ios/` или запускается вручную: **Actions → «Build iOS IPA (unsigned)» → Run workflow**.

Готовый файл `Ritm-unsigned.ipa` появляется в артефактах сборки и в разделе **Releases** репозитория. Установка на iPhone — через **Sideloadly** или **AltStore** с вашим Apple ID; после установки на устройстве нужно довериться профилю разработчика (Настройки → Основные → VPN и управление устройством). Бесплатный Apple ID подписывает приложение на 7 дней.

## 2. Аккаунт

Аккаунт создаётся **только внутри браузера** и никуда не отправляется.

**Регистрация:** вкладка «Регистрация» → имя, логин (3–24 символа: латиница, цифры, `. _ -`), пароль (минимум 4 символа).

**Вход:** вкладка «Вход» → логин и пароль.

> Пароль не хранится в открытом виде — сохраняется его хеш. Это защита от случайного просмотра, но **не** полноценная защита от злоумышленника с доступом к устройству. Не используйте важные пароли.

Сессия сохраняется: при повторном открытии приложение сразу откроет ваш профиль. Выйти можно в разделе **Профиль → Аккаунт → Выйти**.

## 4. Создание и редактирование привычки

Нажмите **«+ Новая привычка»**. Доступные поля:

- **Название** — обязательное.
- **Описание** — зачем вам эта привычка (до 300 символов).
- **Категория** — Здоровье, Спорт, Развитие, Работа, Быт, Другое или своя.
- **Цель за день** — сколько раз нужно выполнить (например, 8 стаканов воды). При цели больше 1 появляется единица измерения и счётчик-степпер.
- **Иконка** — 32 варианта.
- **Цвет** — 12 цветовых меток.
- **Частота** — пять режимов:
  - **Ежедневно** — каждый день;
  - **По дням** — выбранные дни недели (например, Пн, Ср, Пт);
  - **Интервал** — раз в N дней, отсчёт с сегодняшнего дня;
  - **Чётные** — 2, 4, 6, 8…;
  - **Нечётные** — 1, 3, 5, 7…
- **Напоминание** — переключатель + время (HH:MM).

Привычка считается запланированной на день по выбранной частоте. Отметки до даты создания не учитываются.

**Изменение:** «Привычки» → карточка → **Изменить** (или «Детали» → «Изменить»).
**Удаление:** в редакторе кнопка «Удалить» — необратимо. Чтобы сохранить историю, используйте **архив** (🗄): привычка скрывается из «Сегодня», но статистика остаётся.

## 5. Ежедневная отметка выполнения

На экране «Сегодня»:

- **Обычная привычка (цель 1):** кнопка с галочкой. Нажатие отмечает выполнение, повторное — снимает.
- **Привычка с целью:** счётчик `− 3/8 +`. Кнопка «+» увеличивает, «−» уменьшает, при достижении цели строка помечается выполненной.
- При выполнении — анимация отметки, короткий звук (можно отключить) и конфетти, когда закрыт весь план дня.
- Достижения за серии и цели показываются всплывающими уведомлениями.

Смена суток отслеживается автоматически: в полночь план обновляется.

## 6. Аналитика

Раздел **Аналитика** — период переключается селектором (Неделя / Месяц / Год / Всё время):

- **Процент выполнения** — доля выполненных из запланированных, с трендом к прошлому периоду.
- **Выполнено из запланированных**, **дней с активностью**, **лучшая текущая серия**.
- **Календарь выполнения** — тепловая карта за ~6 месяцев: чем насыщеннее клетка, тем больше привычек закрыто в этот день.
- **Динамика выполнения** — линейный график (по дням или по неделям).
- **По дням недели** — в какие дни вы стабильнее.
- **Категории** — сравнение процента выполнения по категориям.
- **Рейтинг серий** — текущая и лучшая серия по каждой привычке.
- **Эта неделя по дням** — таблица отметок: ✓ выполнено, • частично, · пропуск.

В карточке привычки («Детали») есть календарь за текущий месяц и мини-сетка последних 28 дней.

## 7. Достижения

Восемь наград за прогресс: первая отметка, серия 7 дней, серия 30 дней, идеальная неделя (100%), пять активных привычек, 100 выполненных дней, привычки в 3+ категориях, 365 выполненных дней. Заблокированные показаны с 🔒, полученные — с иконкой и датой.

## 8. Напоминания

- Включите **системные уведомления** в разделе «Профиль → Напоминания» (браузер запросит разрешение).
- Время задаётся индивидуально для каждой привычки.
- Напоминание приходит, если привычка **запланирована на сегодня и ещё не выполнена**, и если прошло **не более 90 минут** от назначенного времени.
- Дополнительно в 20:00–20:30 приходит вечерняя сводка о незакрытых привычках.
- Кнопка «Тестовое уведомление» проверяет, что всё работает.

> **Важно:** у приложения нет серверной части, поэтому напоминания срабатывают, **пока приложение открыто** (в том числе в фоновой вкладке). Полноценные push-уведомления при полностью закрытом приложении требуют стороннего сервера рассылки.

В колокольчике на верхней панели — счётчик незакрытых привычек; там же точками отмечаются ожидающие напоминания.

## 9. Синхронизация и перенос данных

Три независимых способа в разделе «Профиль → Данные»:

1. **Экспорт файла** — сохраняет привычки, историю и настройки в JSON-файл.
2. **Импорт файла** — загружает резервную копию (текущие данные заменяются).
3. **Код синхронизации** — текст строки, начинающейся с `RITM1.`. Скопируйте его на одном устройстве, на другом — «Вставить код» → «Применить». Удобно для быстрого переноса без файлов.
4. **Облако (необязательно)** — укажите REST-эндпоинт (принимает и отдаёт JSON) и токен. Доступны «Загрузить», «Отправить» и «Слить» (объединение локальных и серверных данных: привычки сопоставляются по id, для отметок берётся максимум значения за день — данные не теряются).

Автоматически создаётся локальная резервная копия (по одной на день, хранятся 7 дней).

## 11. Дополнительные разделы

### Шахматы
Игра против компьютера: выбор уровня сложности и цвета фигур. Поддерживаются все правила — рокировка, взятие на проходе, превращение пешки, шах, мат, пат и ничьи (правило 50 ходов, недостаток фигур, троекратное повторение). Ходы записываются в нотации SAN, есть подсказка, отмена хода и список взятых фигур. Статистика побед/поражений/ничьих и история последних партий сохраняются в профиле.

### Блэкджек
Классическая карточная игра против дилера. Используется шуз из 6 колод (312 карт), который тасуется заново, когда карт становится мало. Перед раздачей выберите ставку (10–500 фишек); игрок и дилер получают по две карты, вторая карта дилера закрыта. Стоимость карт: 2–10 по номиналу, J/Q/K = 10, туз — 1 или 11 (по ситуации). Доступны ходы **«Ещё»** (взять карту), **«Хватит»** (остановиться) и **«Удвоить»** (удвоить ставку и получить одну карту). Дилер добирает до 17 и останавливается на любых 17 (S17). Блэкджек (туз + «десятка» с раздачи) оплачивается 3:2, перебор — проигрыш, равенство очков — ничья (push). Ведётся статистика (раздачи, победы, поражения, ничьи, блэкджеки, лучший выигрыш) и история последних раздач; счёт фишек сохраняется в профиле.

### Тренировки
Четырнадцать готовых программ, отмеченных уровнем сложности (начальный / средний / продвинутый) и целью (похудение, набор массы, поддержание формы). Фильтры по уровню и цели помогают подобрать подходящий план. Внутри каждой программы — занятия с пошаговыми описаниями упражнений, длительностью и рекомендациями по выполнению; отмечайте выполненные, и прогресс виден на полосе. Вкладка «Мои планы» позволяет составить личный план с целью и чек-листом, а «Журнал» — фиксировать отдельные тренировки и видеть суммарные минуты.

### Питание
Калькулятор суточной нормы калорий и БЖУ. Введите пол, возраст, рост, вес и уровень активности — расчёт идёт по формуле Миффлина — Сан-Жеора с учётом выбранной цели (похудение −20 %, поддержание, набор массы +15 %). Рядом — индекс массы тела, норма воды и ориентировочный здоровый вес. Вкладка «Продукты» — структурированная база из 100+ позиций с калорийностью и БЖУ **на 100 г**, с поиском и категориями (мясо, рыба, крупы, овощи, фрукты и др.); можно добавить свой продукт. Вкладка «Дневник» — записи по приёмам пищи (завтрак / обед / ужин / перекус) с авторасчётом порции, итогами за день и учётом выпитой воды.

### Рецепты
Каталог из 24 блюд. Фильтры по категории (завтрак, обед, ужин, салаты, супы, десерты, напитки, перекусы), калорийности и времени приготовления, поиск по названию и ингредиентам. Любимые рецепты отмечаются звёздочкой и собираются во вкладке «Избранное». Можно добавить собственный рецепт с ингредиентами и шагами. У каждого блюда указаны подробный список ингредиентов, пошаговые инструкции приготовления и калорийность на порцию.

### Музыка
Локальный плеер: импортируйте свои аудиофайлы (они хранятся в браузере в IndexedDB), создавайте плейлисты, отмечайте избранное, пользуйтесь очередью, перемешиванием и повтором. В библиотеке — три демо-композиции и шесть чарт-композиций («поп-хит», «танцпол», «хип-хоп бит», «рок-энергия», «русский поп», «электро-клуб») — они синтезируются прямо в браузере с ритмической основой, чтобы раздел можно было опробовать без своих файлов.

> **О Яндекс.Музыке.** Прямое подключение внешнего стриминга и загрузка треков из чартов невозможны: у сервиса нет публичного API для сторонних приложений, а сам контент защищён авторским правом. Поэтому раздел работает как собственный плеер с локальной библиотекой, а чарт-подобные композиции сгенерированы офлайн; пояснение показано и внутри самого раздела.

## 13. Частые вопросы

**Где хранятся мои данные?**
В локальном хранилище браузера (localStorage). Они не покидают устройство, если вы сами не включите облако.

**Я очистил данные браузера — привычки пропали.**
Да, очистка хранилища удаляет данные. Регулярно делайте экспорт файла.

**Как перенести данные на телефон?**
Вариант 1: экспорт/импорт файла. Вариант 2: код синхронизации. Вариант 3: облачный эндпоинт.

**Напоминания не приходят.**
Проверьте разрешение в браузере и что приложение открыто. На iOS уведомления работают только для установленного на «Домой» приложения.

**Приложение стало медленным при большом числе привычек?**
Приложение рассчитано на сотни привычек (проверено до 120+ с историей). Если стало тяжело — заархивируйте неактуальные привычки.

## 14. Ограничения текущей версии

- Нет серверной части: данные между устройствами переносятся вручную или через ваш облачный эндпоинт.
- Напоминания работают при открытом приложении.
- Пароль защищает от посторонних лишь базово (локальное хранилище не шифруется).
- Раздел «Музыка» работает с локальными файлами; внешний стриминг (Яндекс.Музыка и подобные) не подключён — у сервисов нет публичного API для сторонних приложений.
